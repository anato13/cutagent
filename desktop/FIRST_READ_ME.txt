ANATO12 STUDIO

1. Extract this entire folder from the ZIP first.
2. Open START_HERE.html in your web browser for the beginner guide.
3. Install 64-bit Python 3.12 or 3.13 from python.org.
   Check "Add python.exe to PATH" during installation.
4. Double-click SETUP.bat and leave the setup window open.
5. Double-click START_ANATO12.bat.

You can import, preview, trim and export without AI.
For optional local transcription, close the app and run INSTALL_SPEECH.bat.

This package contains source code and Windows launchers, not a prebuilt EXE.
BUILD_WINDOWS.bat can make an EXE on a Windows PC after source setup.
The Windows CI workflow is also included in this package.

Your recordings stay on your computer. Source recordings are never overwritten.
